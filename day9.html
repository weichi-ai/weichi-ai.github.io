02 · DIRECTORIES

目录详细解释


文件/目录作用生活化比喻
app/Next.js 核心目录，管理页面、路由、接口公司办公楼
page.tsx一个页面入口一个办公室
layout.tsx页面公共布局公司大厅装修
globals.css全局样式公司统一装修标准

api/后端接口公司客服电话
route.tsAPI 具体处理逻辑客服人员

03 · APP DIRECTORY

核心：app 目录


app 是 Next.js 的核心，一个文件/文件夹就是一个路由。

app/page.tsx —— 网站首页，对应访问路径 /。

export default function Home(){

 return (

   

Hello Next.js

 )

}

生活比喻：公司大门口的接待大厅——别人进入公司第一眼看到这里。

app/layout.tsx —— 全局布局，所有页面共享（导航栏、Footer、全局字体）。

export default function RootLayout({ children }){

return (

{children}

)

}

生活比喻：整栋办公楼的装修模板——无论财务部、技术部还是市场部，大厅和楼层结构都一样。

app/dashboard/page.tsx —— 自动生成路由 /dashboard。

生活比喻：公司里的某个部门——比如 dashboard = 数据分析部门。

04 · API

API 接口


app/api/users/route.ts 提供后端能力：前端说"我要用户列表"，调用 GET /api/users，后端返回数据。

export async function GET(){

return Response.json({

 users:[]

})

}

生活比喻：公司服务热线——客户打电话"我要查询订单"，客服查询后告诉你。

05 · COMPONENTS

components 组件


components

│

├── Button.tsx

├── Navbar.tsx

└── UserCard.tsx

作用：复用 UI 组件——写一次 Button，每个页面都能用，不用重写。生活比喻：公司里的标准化设备（办公桌、打印机、电话），每个部门都可以使用。

06 · LIB

lib 目录


这里放业务工具：auth.ts（用户认证：login/logout/checkUser）、db.ts（数据库连接）、utils.ts（通用函数：日期格式化）。

生活比喻：auth.ts 是人事部门（员工身份/入职/离职），db.ts 是档案管理员（查员工资料），utils.ts 是公司行政助手（处理各种杂事）。

07 · DATABASE

database 目录


users

id

name

email

存数据库结构（schema.sql）。生活比喻：公司员工档案柜。

08 · PUBLIC

public 目录


存静态资源：图片、图标、favicon，访问路径直接 /logo.png。生活比喻：公司宣传仓库——存 Logo、海报、宣传册。

09 · CONFIG

config 目录


export const site={

 name:"AI助手",

 url:"xxx.com"

}

存配置。生活比喻：公司制度手册——规定公司名字、联系方式、默认设置。
