01

METAPHOR

用一个餐厅比喻 Next.js 和 Supabase

Next.js = 餐厅 + 服务员 + 厨房管理系统

你看到的：菜单页面、点餐界面、订单流程、用户体验——这些都是Next.js 负责的。

比如：客人打开网站 → 看到页面 → 点击按钮 → 提交订单 → 页面更新，这些交互体验，属于 Next.js。

「Next.js 负责“怎么接待客人，让餐厅运转起来”」

Supabase = 餐厅的仓库 + 账本 + 后厨数据中心

Supabase 负责：存储用户账号、保存订单、管理商品信息、用户登录认证、文件上传。

比如：今天来了 100 个客户，他们点了什么？会员是谁？订单多少钱？这些数据都放在 Supabase。

「Supabase 负责“记住发生过什么”」

3. 检查我的项目，确定 Supabase 是否已经初始化。如果尚未初始化，请运行 supabase init 进行初始化。
